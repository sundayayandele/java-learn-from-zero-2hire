How this course works on ITLearning

  1. Work through the modules in order. Each topic has a Lesson page (read it and type the code yourself, then watch the embedded videos) followed by a Check your understanding quiz.
  2. Take every topic quiz and aim for 70% or more. The quizzes are there to help you learn and keep pace, not to grade you: attempts are unlimited and you see feedback straight away. A topic counts as complete when you've viewed the lesson and attempted its quiz. If you score under 70%, reread the explanations and try again; the exam draws on the same topics.
  3. Do the practice tasks and module projects listed at the end of each lesson and module.
  4. Build your capstones from week 15: Capstone 1 plus one other, then defend them in a 20-minute capstone defence (demo, code questions and a live change). Each capstone page has the brief, the architecture diagrams and a step-by-step build guide. Submit each one in its Submission assignment; it is marked out of 24 with the rubric, and 17 is a pass.
  5. Keep up the coding practice track (about 3 hours a week): auto-graded Java and SQL interview problems. Submit your progress at the coding practice checkpoint.
  6. Sit the end-of-phase assessments: the exam once you've attempted all 27 topic quizzes (60 questions drawn at random, 2 hours, pass mark 70%, two attempts at least 48 hours apart) and the 90-minute live-coding assessment.
  7. Get hired: work through the Getting hired section and submit your checklist.

Phase 2: Professional Backend (weeks 14-24)

From "I can build a Spring Boot service" to "I can be trusted with a production backend in a team": API design and third-party integration, security, a real testing strategy, Git, Docker and CI/CD pipelines, and working with AI coding assistants without losing your judgement. Every example is a payments, banking or fintech scenario, because those integrations (payment gateways, open banking, identity, KYC, card vaults) are exactly what Lagos fintechs, banks and global consultancies hire junior and mid-level Java engineers to build. The phase ends with your junior portfolio and interview preparation.

Prerequisite: Phase 1 (or equivalent): Java 21, SQL, and building a Spring Boot 4 service with JPA, validation, Problem Details and Actuator. Phase 2 builds directly on the Phase 1 starter and capstones.

How to study this phase

Each topic page has the same three parts as Phase 1, in this order:

  1. Read the lesson and type out the code yourself.
  2. Watch the curated videos (checked: real, embeddable, English with captions).
  3. Check your understanding with the scenario CBT. On Moodle it is graded (pass mark 70%, unlimited attempts).

Then do the topic's practice tasks and, each module, at least one module project and its broken-service lab. From week 15, start your Phase 2 capstones; every capstone is a team-ready service with security, a full test pyramid and a CI/CD pipeline with quality gates. Keep up the weekly coding-interview practice track (about 3 hours a week).

How much time this phase takes

Be realistic: Phase 2 is the most demanding phase, because it turns you into someone a team can hand real tickets to. Estimated effort for a learner who finished Phase 1:

Work Hours
27 topics (reading, videos, CBT, practice tasks) 70–80
5 module projects 35–45
5 broken-service labs 15–20
2 capstones (Capstone 1 plus one other) 80–100
Practice track (DSA and SQL, 3 h/week) 30–35
Getting hired, mock interviews, defence and live coding 15–20
Total about 245–300

That is 22–27 hours a week over the 11 scheduled weeks. If you can give 12–15 hours a week, plan for 18–20 weeks instead and tell your mentor; the order of the work stays the same, and nothing in the certificate depends on finishing in 11 weeks. To keep the load manageable, a module project may extend one of your capstones (for example Project 6.C's admin/customer roles inside Capstone 1), and the second capstone can be your strongest stretch, not a third. A third capstone is welcome but optional.

Capstones

Ten integration- and security-heavy fintech capstones, each built on public data or official sandboxes that are free for commercial and non-commercial use, with recorded licences. Complete at least two by the end of the phase: Capstone 1 (the payment gateway hub) plus any one other, and defend them in a 20-minute capstone defence. Capstones 1 and 2 have complete, tested reference solutions, which your mentor shares once your submission has passed.

Deployment and CI/CD

Phase 2 capstones use the same six-platform pipeline as Phase 1 (GitHub Actions, GitLab CI, Azure DevOps, AWS CodeBuild/CodePipeline, Jenkins, Argo CD) with added quality gates: test coverage thresholds, static analysis, dependency and secret scanning, and image scanning. Deployment targets are the same: a VPS (for example SSDNodes), AWS, Azure and GCP.

Certifications

Oracle's Java SE exams are fully covered by Phase 1. Phase 2 prepares the ground for cloud and security credentials: Module 8 starts the AWS material used by AWS Certified Developer – Associate, and Module 6 covers the OWASP and OAuth2 knowledge assumed by vendor security courses. See the certification mapping.

End-of-phase assessments

  • Exam: a 2-hour, 60-question scenario-based CBT covering every Phase 2 topic, taken on Moodle in week 24 (questions drawn at random from a larger bank). Pass mark 70%.
  • Capstone defence: a 20-minute recorded viva on your capstones, including a live change (format and rubric).
  • Live-coding assessment: 90 minutes, one algorithm problem and one secured or integration change to an unfamiliar service (format and rubric).
  • Coding practice checkpoint: at least 70% of the practice track Java and SQL problems passing.

Phase 2 exit criteria

  • All 27 topic CBTs attempted (aim for 70%+).
  • At least one project per module.
  • Capstone 1 plus one other passed against the rubric, each with a green pipeline that enforces quality gates, deployed and secured, and both defended in the capstone defence.
  • Live-coding assessment and coding practice checkpoint passed.
  • End-of-phase exam passed (70%+).
  • Getting Hired checklist complete.
