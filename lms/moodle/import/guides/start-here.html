How this course works on ITLearning

  1. Work through the modules in order. Each topic has a Lesson page (read it and type the code yourself, then watch the embedded videos) followed by a Check your understanding quiz.
  2. Pass every topic quiz at 70%. Attempts are unlimited and you see feedback straight away, so use the explanations to learn. A topic counts as complete when you've viewed the lesson and passed its quiz.
  3. Do the practice tasks and module projects listed at the end of each lesson and module.
  4. Build at least three capstones from week 5: Capstone 1 plus two others. Each capstone page has the brief, the architecture diagrams and a step-by-step build guide. Submit each one in its Submission assignment; it is marked out of 20 with the rubric, and 14 is a pass.
  5. Sit the end-of-phase exam once you've passed all 29 topic quizzes: 60 questions, 2 hours, pass mark 70%, two attempts at least 48 hours apart.
  6. Get hired: work through the Getting hired section and submit your checklist.

Stuck? Ask in the Questions and help forum in this section. Say which topic or capstone, what you tried, and paste the error message.

Phase 1: Foundations (weeks 1-13)

From zero programming experience to building your first production-style Spring Boot 4 services: modern Java 21 (and Kotlin), concurrency and the JVM, relational and NoSQL databases, and Spring Boot fundamentals. Every example uses banking and payments scenarios, because those are the systems Lagos fintechs, banks and global consultancies hire Java engineers to build.

Status: Phase 1 pilot. This phase is fully built. Phases 2 and 3 are mapped in the full curriculum and will be built after review.

How to study this phase

Plan for 10–15 hours per week for 13 weeks. Each topic page has three parts, and you should do them in this order:

  1. Read the lesson and type out the code yourself. Copy-paste teaches nothing.
  2. Watch the curated videos (all checked: real, embeddable, English with captions). They reinforce the reading from a second voice; they don't replace it.
  3. Check your understanding with the scenario CBT at the end of the topic. On Moodle it is graded (pass mark 70%, unlimited attempts); on GitHub the answers are folded under each question.

Then do the topic's practice tasks and, each module, at least one module project. From week 5, start your capstones.

Capstones

Ten financial-institution capstones built on public datasets that are free for commercial and non-commercial use, each with a recorded licence. Complete at least three by the end of the phase: Capstone 1 (the ledger) plus any two others. Two capstones come with complete reference solutions.

Deployment and CI/CD

Every capstone ships with the same pipeline on six platforms: GitHub Actions (primary), GitLab CI (secondary, free gitlab.com), Azure DevOps, AWS CodeBuild/CodePipeline, Jenkins, and Kubernetes manifests with Argo CD for GitOps, plus infrastructure sizing and step-by-step deployment to a VPS (for example SSDNodes), AWS, Azure and GCP.

Oracle certification

Phase 1 Modules 1–2 cover every objective of the Oracle Certified Professional: Java SE 21 (1Z0-830) and Java SE 25 (1Z0-831) exams. See the objective-by-objective mapping and take the OCP after week 13.

A 2-hour, 50-question scenario-based CBT covering every Phase 1 topic, taken on Moodle in week 13. Pass mark 70%.
